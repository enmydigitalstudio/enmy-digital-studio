# Enmy Digital Studio

Abre index.html en el navegador. No requiere instalacion ni dependencias externas.

Archivos: index.html, styles.css, script.js y favicon.svg.

Incluye menu movil, filtros de proyectos, preguntas desplegables y formulario validado que descarga una solicitud en texto. No envia correos; requiere configurar un backend o proveedor de formularios y datos de contacto reales antes de habilitar el envio.

Las muestras de proyectos son conceptuales. Reemplazalas por trabajos reales antes de utilizarlas como portafolio de clientes.

Opcional: sirve la carpeta con python -m http.server 8000 y visita http://localhost:8000.
